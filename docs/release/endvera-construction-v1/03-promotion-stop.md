# Later promotion and mandatory stop runbook

R35 cannot promote a release. A later exact authority must independently supply
and approve public origins, secret references, provider boundaries, Apple and
Google team ownership, signing custody, store records, support ownership,
deployment target and rollback authority.

Before any later promotion, revalidate the exact source commit/tree, package
hash, disclosures, assets, version/build uniqueness, environment names,
provider policies and release checklist. Any drift invalidates the package.

STOP on missing authority, shared credentials, customer data, unsupported
claim, unreviewed privacy change, unbounded provider action, absent rollback,
failed smoke gate or inability to prove the exact release artifact.
