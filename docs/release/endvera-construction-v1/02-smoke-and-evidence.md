# Local smoke and evidence runbook

1. Confirm the Web cockpit, Account, Human Support, privacy and Construction
   support/status routes render from the local server.
2. Confirm the shared mobile app renders the Golden Workflow and Settings
   release information for both iOS and Android export targets.
3. Confirm signed, uploaded, published, deployed and provider-observed states
   are all false in the manifest and visible copy.
4. Regenerate the manifest twice and compare bytes.
5. Run mutation tests for a changed asset, disclosure, path, claim and release
   action; restore every fixture byte-exactly.
6. Store only counts, hashes and non-secret environment names as evidence.

This is local synthetic evidence. It is not device, provider, store, customer,
deployment, Production or Verified-E2E evidence.
