# R34 Requirements Checklist

- [x] Commercial outcome is explicit and separate from legacy task pricing.
- [x] Price and billing honesty are explicit requirements.
- [x] Actor, tenant, role, replay, concurrency and immutability are specified.
- [x] Usage sources and non-billing semantics are closed.
- [x] Support reuses the existing human escalation lifecycle.
- [x] Public capability claims and forbidden claims are testable.
- [x] Client, admin, field and public projections are separated.
- [x] Accessibility and narrow-layout requirements are measurable.
- [x] Provider, customer-data, push/deployment/store boundaries are explicit.
- [x] Success criteria are observable without live providers or customers.
