# Quickstart: R9 Mobile Assistant

1. Use only a disposable local PostgreSQL database and synthetic identities.
2. Start the existing Next.js API and R8 Expo app using the documented local URLs.
3. Sign in as a synthetic owner or office manager and open **Assistant**.
4. Ask `Qu'est-ce que j'ai demain?`, create a clear appointment, submit an ambiguous time and prepare a text to a synthetic contact.
5. Reload and verify persisted history; simulate one unknown outcome and exact retry.
6. Confirm all outbound requests remain `PREPARED_UNSENT` and no external transport exists.

No customer data, external provider, Preview, Production, store service or push is permitted.
