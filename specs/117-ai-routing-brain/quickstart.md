1. Run the targeted R36A unit tests.
2. Confirm canonical-state and calendar requests choose internal tools.
3. Confirm public supplier/person research prepares a citation-required specialist candidate.
4. Confirm restricted-person research is refused.
5. Confirm a complex request prepares the versioned controller candidate.
6. Disable the preferred candidate and confirm only the explicit fallback is selected.
7. Replay the same request and confirm the decision fingerprint is identical.
8. Inspect serialized decisions for raw content, credentials and dispatch flags.
9. Run existing Model Gateway and R36 regression tests.

Expected result: local routing policy passes with zero provider call and zero external effect.
