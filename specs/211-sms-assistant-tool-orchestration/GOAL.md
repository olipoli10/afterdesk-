# /goal - ENDVERA SMS assistant and tool orchestration

## Objective

Build the guarded ENDVERA assistant path described in `plan.md` so a verified
owner can use one ordinary SMS conversation to receive natural answers, cited
public research, evidence-bound property research and safely prepared ENDVERA
actions.

## Autonomous route

1. Reconcile current Git, canonical Brain and user-owned uncommitted work.
2. Freeze the assistant request, lane, answer, citation, tool, evidence, job and
   cost contracts.
3. Implement deterministic routing and corpus tests first.
4. Extend the existing provider-neutral gateway with separate answer-only and
   public-research operations. Do not weaken or rename the historical
   personal-intent contract.
5. Implement injected/disabled OpenRouter Auto Router and Web Search adapters,
   followed by the first six property tools with synthetic fixtures and source
   interfaces.
6. Connect validated results to the existing SMS outbox, detailed reports,
   durable queue and prepared-action gateway.
7. Run proportional unit, integration, PostgreSQL, typecheck, lint and build
   validation; review critical patches through a distinct audit lane.
8. Create useful local commits and a factual Brain checkpoint or reconciliation
   packet without overwriting unrelated Brain work.
9. Activate a bounded real founder route only after current rate/privacy/budget,
   owner consent, encrypted credential, published gateway route and stop controls
   all validate. Preserve exact observed failures.

## Authority boundaries

- The model proposes answers and tool calls; deterministic ENDVERA code owns
  permissions, execution, verification and audit.
- Continue all local, synthetic and injected-transport work without routine GO.
- Do not send customer/employee data, contact third parties, perform a paid
  registry lookup, publish stores or broaden production traffic without exact
  current authority.
- OpenRouter and Web Search spend must remain within the current separately
  validated envelope. Do not infer remaining budget from account credit.
- Never print, commit, log or place credentials in model input.

## Terminal condition

The goal is complete only when the authorized local implementation is green and
the bounded founder route, if all external prerequisites are valid, has durable
evidence for one general answer, one cited public-research answer, one synthetic
property-research answer and one prepared action through the dedicated ENDVERA
number. Otherwise report the exact remaining external blocker and keep broader
R39/R40 readiness claims false.
