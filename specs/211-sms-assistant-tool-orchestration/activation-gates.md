# Activation gates — not a request to enter another credential

This change has not been deployed and does not change the installed APK or live
Twilio number. Credentials should not be pasted into chat or logs. No timer is
required to run the deterministic worker.

## Required before the answer-only route can be enabled

1. Produce a new local release manifest for82 migrations and regenerated client.
   The historical spec21080-migration catalog/receipts stay frozen. Rehearse the
   new schema on a disposable clone and verify data preservation before any
   actual backend upgrade. Current full-root failure is retained, not waived.
2. Review the exact allowed Auto Router models and one provider endpoint, current
   token/tool fees, output/context limits, FX/headroom and aggregate pilot spend.
   Account credit alone is not authorization. No fallback model or wildcard.
3. Verify durable owner inference consent, privacy evidence, encrypted credential
   binding, route/policy publication and stop switches. The code only defines
   the new registry entries; it does not publish them.
4. Set bounded answer configuration only after those checks. Keep research off
   until the owner separately accepts query disclosure to Exa and a current
   operator review of search privacy/terms exists. The ZDR inference flag does
   not prove search-provider retention behavior.
5. Verify protected worker/outbox scheduling and origin ownership. Observe real
   response and cost receipts only under a current exact test mandate. Preserve
   an unknown outcome without retry or refund.

## Property research

The implemented property queue accepts only SYNTHETIC source registries. There
is deliberately no real municipal scraper, owner search, paid registry or
property-progress SMS enabled. Select one municipality and qualify source rights,
versions, access mechanism and freshness before wiring a live adapter.

The source workflow distinguishes assessment-roll names from legal title,
keeps conflicts/staleness, and never searches a person's phone/email. Paid deeds
are a separate capability, not a flag on public search.
