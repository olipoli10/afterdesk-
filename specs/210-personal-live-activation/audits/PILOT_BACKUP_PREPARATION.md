## What the official documentation permits

Public docs retrieved September10,2026; exact account entitlements remain unobserved here.

- A normal child copies schema and data, diverges without changing its parent, and retains its data as history ages out; retained storage still counts. Any existing branch may be the explicit parent. Ordinary clones inherit roles/passwords. Console creation defaults to automatic deletion after one day; API/CLI creation has no expiry by default. Branch protection is a paid feature. These are material retention/access considerations, not reasons to enable it on this Free project. [Manage branches](https://neon.com/docs/manage/branches)
- Snapshots are documented as root-only. They can be preview-restored with `finalize_restore:false`; finalization moves endpoints and changes active branch identity. The guide still says Beta/free but also specifies storage charges beginning May1,2026; do not promise free snapshot storage. If the pilot is a child, taking a snapshot of main68 would capture the wrong database state. Do not detach/reparent/replace the pilot or touch main to make snapshots eligible. [Snapshot versioning](https://neon.com/docs/ai/ai-database-versioning)
- Current Instant restore documentation explicitly limits PITR source/target to roots, despite older child examples still on the page. Therefore do not propose historical PITR on a pilot child. A HEAD reset from parent is separately documented for children; it overwrites the selected child, not a merge. [Instant restore](https://neon.com/docs/guides/branch-restore), [branch workflow skill](https://neon.com/docs/ai/skills/neon-postgres-branches/SKILL.md)
- A compute is needed to query a branch; a checkpoint can exist without one. Never create a replica and call that a backup: it reads the same branch state. [Manage computes](https://neon.com/docs/manage/endpoints/)

**Decision:** prefer ordinary branches, not snapshots or PITR, for the next bounded rehearsal. This is a retained same-project recovery checkpoint, not an independent off-provider disaster-recovery backup.
