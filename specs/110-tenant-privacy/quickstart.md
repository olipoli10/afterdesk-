# R30 Local Quickstart

1. Start a fresh disposable PostgreSQL database and apply the forward-only chain.
2. Seed two synthetic workspaces with projects, evidence, connectors and roles.
3. Create and activate one complete retention policy in workspace A.
4. Inspect owner and field projections and prove recursive minimization.
5. Prepare the same export twice and compare exact canonical result/fingerprint.
6. Request deletion for protected, held, cross-workspace and eligible synthetic evidence.
7. Prove only eligible exact approval creates one local tombstone.
8. Restart Prisma and compare inventory, policy, export and deletion state.
9. Run R30 and proportional regression/mobile/build gates.

No real secret, provider, customer data, external storage deletion, external
write, push, deployment or store action is permitted.
