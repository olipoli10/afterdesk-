# Local validation quickstart

1. Apply migrations to a fresh disposable PostgreSQL database with `prisma migrate deploy`.
2. Seed two client users; initialize a workspace, project `LAVAL` and one contact `Marc` for the first user.
3. Submit the clear meeting phrase and confirm one sourced event.
4. Ask what is scheduled tomorrow using the same explicit reference instant.
5. Submit the identical local SMS envelope twice and confirm one canonical effect.
6. Submit an unverified sender and confirm refusal with no disclosure.
7. Draft the late-arrival message, approve the exact version, simulate delivery once, then prove replay refusal.
8. Log in as the second client and prove all identifiers remain inaccessible.
9. Run targeted tests, disposable PostgreSQL integration tests, lint, typecheck, serialized suite, Webpack production build and `git diff --check`.

No step uses a live provider, phone number, email delivery, customer data or external network.
