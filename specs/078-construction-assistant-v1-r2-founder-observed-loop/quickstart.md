3. Create one synthetic verified CLIENT identity.
4. Start the product on loopback with synthetic local environment values.
5. Start the spec-owned observation guide on a separate loopback port.
6. Give Olivier both local URLs in one `[INFO — aucun GO requis]` message.
7. Wait for the observation packet to become `FOUNDER_COMPLETED`.
