# Contract: Corrected Founder Retest

The authenticated console exposes nine ordered commands and one final non-technical form. Every request carries only an action token and the expected prefilled business message. The server rederives user, workspace, project, contact, provider message identity, action version and database truth.

Unknown fields, out-of-order steps, non-local mode, missing CLIENT authorization, cross-workspace state, changed provider-event bodies, altered outbound versions and a second founder submission are rejected closed.

The only permitted final verdicts are:

- `FOUNDER_OWNED_CORRECTED_CONSTRUCTION_LOOP_OBSERVED_PASS`
- `REWORK`
- `REJECT`
