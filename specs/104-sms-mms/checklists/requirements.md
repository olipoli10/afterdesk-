# Specification quality checklist

- [x] Outcome is written in user and business terms.
- [x] R24 extends R4 instead of creating a second messaging engine.
- [x] Inbound routing and ambiguity behavior are explicit.
- [x] Idempotency and concurrent replay are measurable.
- [x] SMS and MMS boundaries are explicit.
- [x] Selected evidence is reused rather than downloaded from a provider.
- [x] STOP, START and HELP behavior is explicit.
- [x] Consent is purpose-bound and evidence-backed.
- [x] Exact approval remains separate from dispatch preparation.
- [x] Local delivery state cannot masquerade as provider proof.
- [x] Owner/office and field-worker projections are separated.
- [x] Raw phones, tokens and remote URLs are prohibited from new persistence.
- [x] Tenant and cross-project refusal are explicit.
- [x] External transport is prohibited.
- [x] Success criteria are observable.
- [x] Non-goals prevent provider activation and compliance overclaim.
