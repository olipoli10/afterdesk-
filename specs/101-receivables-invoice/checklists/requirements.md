# R21 Requirements Checklist

- [x] Product outcome is economic and observable.
- [x] R0, R6, R17 and R20 reuse is explicit.
- [x] Invoice issuance is local state, not provider delivery.
- [x] Promise-to-pay is distinct from payment received.
- [x] Exact replay, concurrency and restart gates are testable.
- [x] Financial role separation is explicit.
- [x] External transport and provider activation remain forbidden.
- [x] Lockfiles and dependencies remain unchanged.
