# Goal: R38C secretary command entry

## Objective

Make all seven virtual-secretary capabilities actionable from TextAssist through the existing assistant and owned prerequisite surfaces, without another form, auto-submission or external effect.

## Authority

Local code, local tests, local Git commits and canonical Brain checkpoint only.

## Forbidden

Credentials, provider calls, OAuth, customer data, SMS/call/email transport, external writes, spending, push, Preview, Production, deployment and store action.

## Done when

- Seven entries are deterministic and actionable.
- Prefill is bounded and never auto-submitted.
- Focused mobile validation and boundary checks pass.
- Product and Brain are clean local commits.
