# Research

## Findings

- The existing site must remain intact; TextAssist and Construction are additive surfaces.
- R36T changed the release definition and mobile config, making the older R36K market hash and R35 release manifest stale.
- Those failures are derived-artifact drift, not product regressions; both can be refreshed locally without credentials.
- A Windows host can verify configuration and export JavaScript bundles for iOS/Android/Web, but cannot honestly produce an iOS binary and currently lacks Android SDK/JDK prerequisites.
- The next four roadmap releases require distinct authority and observed evidence: provider sandbox, founder full loop, design-partner pilot and production V1.

## Decision

Treat the local product scope as closed only after every current constituent validator, regression suite and build gate passes. Keep all external claims false.
