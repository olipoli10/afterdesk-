# Local market-readiness quickstart

1. Run the R36G mobile contract tests.
2. Run the R35 release-package regression.
3. Run the unified readiness command once R36K exists.
4. Read the generated report by target: Web, iOS and Android.
5. Treat `EXTERNAL_AUTHORITY_REQUIRED` as an exact handoff list, not as a request to invent credentials or publish.

Forbidden in this quickstart: EAS build/submit/update, Apple or Google account login, signing, upload, deployment, provider calls and customer data.
