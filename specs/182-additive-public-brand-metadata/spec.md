# Feature Specification: Additive Public Brand Metadata

**Status**: Accepted for autonomous implementation

## Requirements

- Preserve the accepted homepage and every historical offering.
- Describe ENDVERA as an operating assistant plus managed human-backed work in root metadata.
- Give the installable Web identity construction-assistant language without claiming providers or publication.
- Keep `/textassist`, `/construction` and `/account-deletion` discoverable.
- Add no dependency, external effect or invented availability claim.

## Success Criteria

Metadata and manifest are bilingual-neutral, additive, assistant-first and covered by deterministic regression tests.
