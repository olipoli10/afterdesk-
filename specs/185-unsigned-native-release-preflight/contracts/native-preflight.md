# Native Preflight Contract

The report may state `LOCAL_UNSIGNED_NATIVE_PREFLIGHT_READY`. It may not state that an IPA, APK or AAB was built. iOS binary status is blocked by `MACOS_XCODE_REQUIRED`; Android binary status is blocked by `ANDROID_SDK_AND_JDK_REQUIRED` on the observed host. Signing, upload, submission, publication and external build are false.
