# Research

Expo's bundled config types support a `locales` map for per-language native metadata. This Windows host has no Android SDK, JDK, adb or EAS executable, and cannot build an iOS simulator binary. The correct local ceiling is therefore configuration, static export and unsigned-build prerequisite readiness—not a fabricated IPA/APK.

The R35 packager still expected the retired Expo icon directory while current app config uses the accepted ENDVERA PNG set. It also pointed account deletion at an authenticated privacy page. Both are corrected to current product truth.
