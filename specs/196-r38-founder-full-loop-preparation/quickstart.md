# Quickstart

1. Run the R38 launcher from the repository root.
2. The launcher validates a named disposable PostgreSQL instance, migrates it, creates the synthetic founder and prints one expiring access URL.
3. Open that URL once. It signs in locally and redirects to the only test surface.
4. Follow the single orange action shown at each stage.
5. Complete the human ratings once. Do not repeat the session.
6. Closeout validates the seal against PostgreSQL before any verdict is recorded.

No OpenRouter key or external connector is needed.
